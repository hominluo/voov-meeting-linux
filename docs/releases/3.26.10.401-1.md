# VooV Meeting 3.26.10.401 (1)

First **native** release of VooV Meeting for Linux — no Wine anywhere.

The client is Tencent's official Linux build of Tencent Meeting 3.26.10.401
(the China product; Tencent ships VooV for Linux not at all) with two small
binary patches that switch it to VooV's regional settings and endpoints. It
runs natively, connects to `conn.voovmeeting.com`, and is packaged with
native desktop integration.

This release replaces the previous Wine-based `3.43.0.510` releases, which
have been removed.

## Source

- Application: Tencent's official
  `TencentMeeting_0300000000_3.26.10.401_x86_64_default.publish.officialwebsite.deb`
  (197,268,516 bytes,
  MD5 `72e0e0023e1d1e6d4123fba28821aea1`,
  SHA-256 `70f37b029209c0ef91be9813eebf6650c6cb9a00f7c718490158773e2fe6acaf`).
- Patches: `scripts/patch-linux-build.py`, described in
  [docs/REVERSE-ENGINEERING.md](../REVERSE-ENGINEERING.md) — the settings
  hook (`+0x420`/`+0x4c8`) and the endpoint string table.

## What works

- Native startup on X11 (and through XWayland on Wayland sessions) — the
  client ships its own Qt runtime, so no Wine and no system Qt is needed.
- The patched client establishes and holds its signaling connection to
  `conn.voovmeeting.com` instead of the China `conn.wemeet.tencent.com`
  (verified with an `LD_PRELOAD` getaddrinfo/connect tracer).
- State goes to the standard XDG directories; the `/opt` tree stays
  read-only.

## Not yet verified

- Signing in with a VooV account (the build reports version 3.26.10.401 and
  channel `0300000000`; server acceptance of that identity is the main open
  question).
- Joining a meeting; camera, microphone, screen sharing.

## Notes

- The window title and parts of the UI still show 腾讯会议 (China product
  branding).
- Update/telemetry endpoints still point at Tencent Meeting's China servers
  (`report.meeting.tencent.com`, `updatecdn.meeting.qq.com`) — cosmetic.
- The Flatpak disables the embedded browser's Chromium sandbox (it cannot
  run inside the Flatpak sandbox).
- The AppImage needs FUSE 2, or run it with `--appimage-extract-and-run`.
- The Flatpak needs `org.freedesktop.Platform//25.08`; Flatpak downloads it
  from Flathub on first install.
- The bundled Tencent binaries are proprietary; two libraries are
  redistributed in patched form. Only the scripts and packaging are MIT
  licensed.

See `SHA256SUMS` for the checksums of all release assets.
