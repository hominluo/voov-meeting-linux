# VooV Meeting 3.43.0.510 (1)

First public build — an unofficial Linux port of VooV Meeting, derived from
Tencent's official Tencent Meeting **3.26.10.401** Linux package.

## Working

- Native X11/XWayland client starts and reaches the login screen
- Signaling and QUIC endpoints patched to `conn.voovmeeting.com` and
  `quic.voovmeeting.com`
- Launcher keeps the desktop locale and timezone (upstream forces
  `LC_ALL=zh_CN.UTF-8` and `TZ=Asia/Shanghai`)
- Packages: `.deb`, `.rpm`, Flatpak, AppImage, plus an Arch `PKGBUILD`

## Verified

- Native, AppImage and Flatpak runs show the window and resolve
  `conn.voovmeeting.com`
- `.deb` installs cleanly on Debian 12 (`dpkg -V` clean)
- `.rpm` installs cleanly on current Fedora (`rpm -V` clean)
- Arch package builds from the released `.deb`

## Not yet verified

- VooV account login end-to-end
- Joining a meeting, camera/microphone, screen sharing
- VooV branding — the UI still shows Tencent Meeting / 腾讯会议

## Notes

- The AppImage needs FUSE 2, or run it with `--appimage-extract-and-run`.
- The Flatpak needs `org.freedesktop.Platform//25.08`; Flatpak downloads it
  from Flathub on first install.
- The bundled Tencent binaries are proprietary. Only the scripts, patches and
  packaging in the repository are MIT licensed.

See `SHA256SUMS` for the checksums of all release assets.
