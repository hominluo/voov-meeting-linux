# VooV Meeting 3.43.0.510 (1)

VooV Meeting **3.43.0.510** — the international client, not the China-only
Tencent Meeting product — running under Wine and packaged for Linux.

This replaces the first `3.43.0.510 (1)` build, which repackaged Tencent
Meeting 3.26.10.401 with patched signaling endpoints. The version number is
unchanged because the application version did not change; every asset here was
rebuilt from the VooV trees.

## Source

- Application: Tencent's official
  `VooVMeeting_1410000197_3.43.0.510_x86_64.publish.exe`
  (281,696,512 bytes,
  MD5 `a8d7f83c02853ae055ae5f9cfdcae781`,
  SHA-256 `92649c45d6d46e38bdf0142bb9884f8c69a9cf4013c8816ce3a200dc60a330fc`),
  unpacked with 7-Zip and verified file by file.
- Icons: the macOS build's `AppIcon.icns`.
- Wine: 11.22, bundled in the AppImage and Flatpak. The `.deb`, `.rpm` and
  Arch packages use the distribution's Wine.

## What works

- The client starts under Wine and shows the VooV Meeting login window.
- The embedded login page loads from VooV's servers and reaches
  "Email Verification" / "Password Login".
- First start creates a Wine prefix and installs the client into it, so the
  read-only `/opt` tree is never modified.
- All formats are built from one verified application tree.

## Verified on this release

- **AppImage** on a host with no Wine installed: first run creates the prefix
  from the bundled Wine, accepts the service agreement, and shows the login
  window and login page.
- **`.deb`**: all 5762 payload files match `DEBIAN/md5sums`; the launcher's
  first run reaches the login window.
- **`.rpm`**: installs, `rpm -V` reports no differences, and uninstalls
  cleanly on Fedora.
- **Flatpak**: on a fresh install the sandbox reaches the service agreement,
  the login window and the embedded login page.
- **Arch**: the `PKGBUILD` builds a package from the released `.deb` with the
  recorded checksum.
- Wine **9.0**, **10.0** and **11.22** each reach the login window.

## Not yet verified

- Signing in with a VooV account
- Joining a meeting; camera, microphone, screen sharing
- Desktop notifications and the VooV URL handlers

## Notes

- The first start copies about 800 MB into
  `~/.local/share/voov-meeting/prefix` (a reflink on btrfs/XFS), plus the
  Wine prefix: about 1.5 GB in total.
- The AppImage needs FUSE 2, or run it with `--appimage-extract-and-run`.
- The Flatpak needs `org.freedesktop.Platform//25.08`; Flatpak downloads it
  from Flathub on first install.
- The bundled Tencent binaries are proprietary. Only the scripts, the
  `SLWGA.dll` stub and the packaging are MIT licensed.

See `SHA256SUMS` for the checksums of all release assets.
